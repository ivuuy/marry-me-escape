# 碰到我，就跟我结婚。

一款纯前端、完全离线的 **3D 小屋逃脱游戏**。双击 `index.html`，用支持 WebGL 的 Chrome、Edge 或 Safari 打开即可。不需要安装依赖、启动服务器或登录。

## 玩法

- 点击“开始逃婚”，随机出生在家里的安全角落。
- 地板可以走。碰到家具、绿植或墙壁立即失败。
- 找到打开的粉色大门，角色完整越过门槛才算获胜。
- 方向键 / WASD 移动，按住 Shift 慢走，R 重新出生，Esc 暂停。
- 小屋视角：拖动空白处旋转、上下拖动调整俯仰、滚轮缩放，也可以按住粉色角色拖动。
- 第一人称：点击画面左上角“第一人称”，拖动画面看四周，方向键 / WASD 相对视线移动。
- Q / E 转向，V 切换视角。“复位”恢复镜头。
- 手机提供方向按钮和“慢走”开关，拖动画面转动镜头。
- 切换窗口或把页面放到后台会自动暂停。
- 结算后可以下载 PNG 战绩卡。成功次数、最快时间保存在当前浏览器本地。

## 作品说明

渲染采用本地内嵌的 Three.js（MIT 许可）。房间、家具、人物是真实的 3D 网格，带实时光照、阴影、透视镜头和可旋转的正交镜头；材质贴图由程序在本地生成。

所有样式、逻辑、3D 引擎、模型生成与合成音效均打包在 `index.html` 中。分享这一个文件即可，无外部图片、字体、脚本、CDN 或运行时网络请求。浏览器内容安全策略也禁止网络连接。手机自适应、跟随系统明暗主题，支持减少动画偏好；切换视角不改变游戏规则和碰撞范围。

碰撞使用圆形角色与圆形 / 圆角矩形家具的距离检测，位移拆分为不超过 2 像素的小步，防止高速穿墙。随机出生点从出口可达区域中挑选，避免开局卡死。

## 修改与打包

- `src/game.js`：移动、碰撞、出生区域、计时、记录、结算。
- `src/scene3d.js`：3D 模型、材质、灯光、镜头和人物。
- `src/template.html`：页面结构与样式。
- `vendor/`：Three.js 引擎及完整许可证，不需要联网安装。
- 执行 `python3 build.py`，即可重新生成单文件作品。

调整 `src/game.js` 的 `SPEED` / `SLOW` 可更改速度，`furniture` / `walls` 可调整房间，`zones` 可调整出生区域。3D 版本的个人记录单独保存。
